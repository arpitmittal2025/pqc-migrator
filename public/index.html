Find quantum-vulnerable cryptography, replace it, and prove it still works.

Shor’s algorithm breaks RSA, ECC and Diffie–Hellman. NIST standardised the replacements in 2024. This tool does the migration: it reads Python source, works out what each cryptographic call is for, picks the right NIST algorithm, rewrites the code, and then runs the rewritten program using real ML-KEM and ML-DSA.
